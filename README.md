# DisplayPilot

A Windows tray utility for your displays: change the primary monitor in one click or with a hotkey, switch resolution, refresh rate and HDR, save complete display scenes with your window layout, and swap automatically when a game starts.

**[Download the latest release](https://github.com/sohiaburrehman-prog/DisplayPilot-Releases/releases/latest)**

| File | What it is |
| --- | --- |
| `DisplayPilot-Setup-<version>.exe` | Installer. Per-user, no admin needed. Needs the [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64). |
| `DisplayPilot-Portable.zip` | Self-contained. Unzip and run, nothing else to install. |
| `SHA256SUMS.txt` | Checksums for both files. |

Windows 10 or 11, x64.

## Trial and licence

Every feature is available for 14 days. After that, changing the primary display stays free; resolution, refresh, HDR, scenes, window layouts, auto-swap profiles and the command line need a licence key. Restoring or reverting a display change is never blocked, and your settings and scenes are kept either way.

DisplayPilot has no analytics or advertising and checks licence keys on your PC. The optional update check reads this page's release list and nothing else.
